## Matlab Scripts (Run First)
- Model.m : Source file containing equations and simulation routines for tirzepatide
- pk_script.m : script that generates all necessary data for pk analysis and plotting
- pd_script.m : script that generates all necessary data for pd analysis and plotting
- sensitivity_analysis.m : script that generates sensitivity data for plotting

## R Script
- plot_driver.R : runs all R scripts in order of plot appearance on paper (only one you need to run)
- single_dose.R : plots the single dose image
- pk_sensitivity_analysis.R : plots the pharmacokinetic sensitivity analyis
- pd_sensitivity_analysis.R : plots the pharmacodynamic sensitivity analysis
- violin_BMI_BW_distribution.R : plots the violin distribution for BMI and BW 
- percent_change_time.R : plots the expected change in bodyweight after 1 year
- percent_change_FFM_FM.R : plots the expected change in FFM and FM after 1 year
- BMI_vs_CL_Vd.R : plots the allometric fits on BMI
